# Pavithran V — 3D Developer Portfolio Website

> Modern **3D Developer Portfolio Website** created using **HTML, CSS & JavaScript**, customized with 100% of the resume details of **Pavithran V** and his photo.

---

## 🌟 Key Highlights & Engineering Features

- **3D Interactive Developer Card**: Pavithran's photo rendered in a 3D perspective card (`perspective: 1200px`) that smoothly tilts on mouse movement with specular glare and floating 3D tech badges.
- **Background 3D Particle Mesh**: Lightweight 3D particle constellation responding to cursor position.
- **Typewriter Effect**: Cycling roles (*"Full-Stack Web Developer"*, *"Python & Django Specialist"*, *"Backend Engineer"*, *"REST API Architect"*).
- **Strict, Non-Overlapping Section Separation**:
  1. **Home**: Hero presentation with photo, roles, summary, and action buttons.
  2. **About Me**: Clear 2-column layout with personal bio and professional & soft skills.
  3. **Education**: Dedicated academic cards for B.E. (8.0 CGPA / 80.91%) and HSC (73.34%).
  4. **Skills**: Categorized strictly into Languages, Frameworks, Databases, Tools, Core Concepts, and AI/Cloud.
  5. **Projects**: Flagship Academic Project (*Cyber Sentry*, SIH 2026) with interactive test algorithm modal, plus Production Web App with RBAC & OTP, and AI Chatbot Integration.
  6. **Certifications & Achievements**: NVIDIA DLI, AWS Cloud Practitioner, and Skill Intern.
  7. **Interests & Activities**: Open-source, AI/ML exploration, and competitive coding.
  8. **Contact**: Direct details (Email, Phone, Location, GitHub, LinkedIn) with 1-click copy + direct message form.
  9. **ATS Official Resume Modal**: Printable clean resume layout with 1-click PDF print.

## 🚀 How to Run Locally

### Option 1: Double-Click
Simply double-click `index.html` in Windows Explorer to open it in Chrome, Edge, or any browser.

### Option 2: Using Node
```powershell
npm start
```
*(Or `npx serve .`)*
