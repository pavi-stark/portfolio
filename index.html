Cyber Sentry - AI-Based Fake Identity & Document Screening System

Python FastAPI React Tailwind CSS Docker Render
  • Built a multi-modal identity and document verification system for border checkpoints and airport kiosks (Smart India Hackathon 2026, Problem Statement 26188) using FastAPI, React and Tailwind CSS.
  • Implemented ICAO Doc 9303 MRZ parsing with 7-3-1 weighted check-digit recalculation, and Verhoeff checksum validation for Aadhaar, to mathematically catch forged document fields.
